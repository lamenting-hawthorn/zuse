# Terminal symbols

`SymbolsNerdFontMono-Regular.woff2` is Symbols Nerd Font Mono from Nerd Fonts
v3.4.0, losslessly compressed from the upstream TTF with fontTools 4.66.0
and Brotli. It provides shell prompt and powerline symbols without
replacing the application's normal monospace text font.

Source: https://github.com/ryanoasis/nerd-fonts/tree/v3.4.0/patched-fonts/NerdFontsSymbolsOnly

The upstream license is included in `LICENSE`.
